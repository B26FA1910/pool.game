# Билльярд — 8 бөмбөг

8 бөмбөгийн билльярд тоглоом: компьютертэй, нэг дэлгэц дээр 2 хүн, **онлайн** горимтой.
Тоглоом өөрөө нэг HTML файл (`public/index.html`), онлайн горимыг Cloudflare Worker + Durable Object хангана.

## Боломжууд

- **Горим:** компьютертэй (хялбар / дунд / хэцүү), 2 тоглогч, 🌐 онлайн
- **Дүрэм:** бүтэн (1–7) / судалтай (9–15), алдаа гарвал цагаан бөмбөгийг хүссэн газраа тавина, 8-р бөмбөгийг цагаасаа өмнө оруулбал хожигдоно
- **Физик:** бөмбөг хоорондын мөргөлдөөн, хөвөөнөөс ойх, дугуй хөвөөтэй нүх, дээд / доод / хажуугийн эргэлт
- **Онлайн:** өрөө үүсгээд 4 оронтой кодоор найзаа урина, өрсөлдөгчийн онилгыг шууд харна, хуудсаа дахин ачаалсан ч кодоор орж үргэлжлүүлнэ, гурав дахь хүн үзэгчээр орно
- **Утас:** 8 Ball Pool шиг удирдлага — ширээн дээгүүр хуруугаа гулсуулж цохиурыг эргүүлнэ, бөмбөг дээр товшвол шууд онилно, «Онилох» дугуйгаар нарийн тааруулна, хүчний самбараас цохиурыг татаж суллана
- **Хэвтээ / босоо:** утсаа хэвтээ барихад хүч зүүн талд, эргэлт ба онилох дугуй баруун талд; босоо барихад ширээ эргэж, удирдлага доор гарна
- **Апп шиг:** ⛶ бүтэн дэлгэц (Android), «Нүүр дэлгэцэд нэмэх» (Add to Home Screen) хийвэл хөтчийн самбаргүй, бүтэн дэлгэцээр нээгдэнэ

## Бүтэц

```
public/index.html   тоглоом (HTML + JS, гадны сангүй)
public/manifest.webmanifest, icon-*.png   нүүр дэлгэцэд нэмэх тохиргоо ба дүрс
src/worker.js       Worker: тоглоомыг үйлчилж, /ws дээр онлайн өрөөнүүдийг (Durable Object) холбоно
wrangler.jsonc      Cloudflare-ийн тохиргоо
```

## Cloudflare дээр байршуулах

> Энэ нь **Worker** төсөл (Pages биш). Pages төсөл Durable Object-оо өөрөө тодорхойлж чадахгүй.

### А. GitHub-аас автоматаар (зөвлөж байна)

1. Энэ repository-г GitHub руу push хийнэ.
2. Cloudflare dashboard → **Workers & Pages** → **Create application** → **GitHub** → энэ repository-г сонгоно.
3. Deploy command нь `npx wrangler deploy` (анхдагч) байгаа эсэхийг шалгаад **Save and Deploy** дарна.
   Wrangler `wrangler.jsonc`-г уншаад Durable Object-ыг өөрөө үүсгэнэ.
4. `https://pool-game.<таны-subdomain>.workers.dev` хаягаар орж **🌐 Онлайн**-г сонгоно.

Цаашид `main` салбар руу push хийх бүрт автоматаар дахин байршина.
Dashboard дээрх Worker-ийн нэр `wrangler.jsonc` доторх `name`-тэй (`pool-game`) таарах ёстой.

### Б. Командын мөрөөс

```
npm install
npx wrangler login
npx wrangler deploy
```

Өөрийн компьютер дээр туршихдаа: `npm run dev` → http://localhost:8787 (хоёр таб нээж тоглож болно).

## Үнэ

Workers Free төлөвлөгөөнд Durable Object (SQLite) ажиллана. Өдөрт 100,000 хүсэлт багтдаг ба WebSocket-ийн 20 мессеж 1 хүсэлтэд тооцогдоно — найзуудын хооронд тоглоход хангалттай.

## Онлайн хэрхэн ажилладаг вэ

Өрөө бүр (`pool-1234`) нэг Durable Object. Тоглогч бүр өөрийн төлвийг (нэр, суудал, ширээний байдал, онилго) өрөөнд илгээж, сервер бусдад нь дамжуулна.
Цохисон тоглогч цохилтын өмнөх байдал ба цохилтын хурдыг илгээдэг тул хоёр талд бөмбөг яг ижил хөдөлнө; цохилтын дараах байдлыг давхар илгээж тулгадаг.
Өөр сайтаас `/ws` руу холбогдохыг Worker хаадаг.

Тоглоомыг claude.ai artifact дотор нээвэл Claude-ийн өөрийн «room» холболтыг ашиглана; энэ серверийг шаардахгүй.
